# Spawn Intensity (Forge 1.20.1) v1.2.0

Spawn multipliers (x1-x100) for mobs (modded hostile mobs too), loot, block drops and chests (non-stackable items are never duplicated),
growth speed, item despawn timer, breeding cooldown, baby growth time, and Apocalypse mode.
Settings: config/spawnintensity-common.toml or /spawnintensity ... ; right-click the Spawn Sit clock for status.
